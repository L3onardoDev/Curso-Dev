# Sobre este termo

Este diretório reúne os conteúdos, exercícios, avaliações e projetos desenvolvidos durante o **1º Termo do curso de Desenvolvimento de Sistemas no SENAI**.

O período é voltado à construção da base técnica necessária para avançar no curso: lógica de programação, primeiros projetos em Python, fundamentos de sistemas operacionais, arquitetura de redes, levantamento de requisitos e atividades práticas.

## Objetivos de aprendizagem

- Desenvolver raciocínio lógico e capacidade de resolver problemas.
- Aprender os fundamentos da programação com Python.
- Compreender conceitos básicos de redes e sistemas operacionais.
- Identificar e organizar requisitos de um sistema.
- Praticar a criação de pequenos programas e projetos.
- Registrar a evolução dos estudos de forma organizada.

## Organização das disciplinas

### [Lógica de Programação](./Logica_De_Programa%C3%A7%C3%A3o)

Aulas, exercícios e atividades práticas de lógica utilizando Python. Os conteúdos incluem variáveis, tipos de dados, operadores, estruturas condicionais, estruturas de repetição, funções e resolução de problemas.

A pasta também reúne projetos como **Biblioteca Digital**, **Elevador de Prédio** e **Shopping Cancela**.

### [Arquitetura de Redes](./Arquitetura_De_Redes)

Materiais introdutórios sobre redes de computadores, comunicação e fundamentos da infraestrutura que permite a conexão entre dispositivos e sistemas.

### [Sistemas Operacionais](./Sistemas_Operacionais)

Conteúdos e atividades relacionados aos fundamentos de sistemas operacionais e ao funcionamento básico dos ambientes computacionais.

### [Levantamento de Requisitos](./Levantamento_Requisitos)

Atividades voltadas à identificação, compreensão e organização dos requisitos necessários para planejar e desenvolver um sistema.

### [Projetos](./Projetos)

Exercícios e pequenos projetos desenvolvidos para aplicar os conceitos de programação na prática.

### [Atividades Avaliativas](./Atividade%20Avaliativa)

Avaliações e atividades somativas realizadas ao longo do termo, incluindo exercícios de programação em Python.

## Como executar os projetos Python

Clone o repositório principal e acesse a pasta do arquivo que deseja executar:

```bash
git clone https://github.com/L3onardoDev/Curso-Dev.git
cd Curso-Dev
python caminho/para/o/arquivo.py
```

Em algumas instalações, utilize `python3` no lugar de `python`.
