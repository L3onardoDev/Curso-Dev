# Sobre o repositório

O **Curso-Dev** é meu repositório de estudos do curso de **Desenvolvimento de Sistemas no SENAI**.

Aqui organizo aulas, exercícios, avaliações, anotações e atividades práticas desenvolvidas ao longo da formação. O objetivo é registrar minha evolução técnica, manter meus estudos organizados e transformar cada conteúdo aprendido em prática de programação.

Este repositório está em constante atualização conforme novos módulos, atividades e projetos são desenvolvidos.

## Objetivos

- Consolidar os fundamentos de programação.
- Praticar lógica e resolução de problemas.
- Documentar o aprendizado ao longo do curso.
- Organizar atividades por módulo e disciplina.
- Desenvolver uma base para projetos web e sistemas completos.
- Acompanhar minha evolução técnica de forma pública e organizada.

## Conteúdos estudados

### Lógica de programação

Exercícios e atividades desenvolvidos para praticar raciocínio lógico, estruturas de controle, repetição, funções, manipulação de dados e resolução de problemas utilizando Python.

### JavaScript

Estudos e exemplos relacionados aos fundamentos da linguagem, organizados na pasta [`JavaScript_Conceitos`](./JavaScript_Conceitos).

### Arquitetura de redes

Materiais e atividades introdutórias sobre conceitos de redes de computadores e comunicação entre sistemas, disponíveis em [`Arquitetura_De_Redes`](./1-Termo/Arquitetura_De_Redes).

### Levantamento de requisitos

Atividades voltadas à compreensão, identificação e organização dos requisitos de um sistema, disponíveis em [`Levantamento_Requisitos`](./1-Termo/Levantamento_Requisitos).

### Avaliações e atividades práticas

Avaliações somativas, exercícios e atividades desenvolvidas durante os módulos do curso estão organizadas dentro das pastas correspondentes, como [`Atividade Avaliativa`](./1-Termo/Atividade%20Avaliativa).

## Como utilizar

### Clonar o repositório

```bash
git clone https://github.com/L3onardoDev/Curso-Dev.git
cd Curso-Dev
```

### Executar arquivos Python

```bash
python caminho/para/o/arquivo.py
```

Em algumas instalações, pode ser necessário utilizar:

```bash
python3 caminho/para/o/arquivo.py
```

### Executar arquivos web

Os arquivos HTML podem ser abertos diretamente no navegador. Para uma experiência melhor durante o desenvolvimento, recomendo utilizar o **Live Server** no VS Code.

## Organização dos estudos

Cada pasta representa uma etapa, disciplina ou conjunto de atividades da formação. A organização pode ser aprimorada conforme o conteúdo do curso cresce e novos projetos são adicionados.
