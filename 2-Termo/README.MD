# Sobre este termo

Este diretório reúne os conteúdos, atividades, avaliações e projetos desenvolvidos durante o **2º Termo do curso de Desenvolvimento de Sistemas no SENAI**.

Nesta etapa, os estudos avançam para a construção de aplicações web, desenvolvimento back-end com JavaScript, modelagem e programação de bancos de dados, criação de interfaces com HTML e CSS e desenvolvimento de projetos integradores.

## Objetivos de aprendizagem

- Desenvolver interfaces web estruturadas e estilizadas.
- Praticar HTML e CSS em páginas e projetos completos.
- Aprender fundamentos de back-end com JavaScript e Node.js.
- Modelar bancos de dados relacionais.
- Escrever e executar comandos SQL.
- Organizar projetos por disciplina, atividade e etapa.
- Aplicar os conteúdos em projetos individuais e em grupo.

## Organização das disciplinas

### [Backend — JavaScript](./BACKEND%20%5BJAVASCRIPT%5D)

Atividades pessoais, exercícios e avaliações voltadas ao desenvolvimento back-end com JavaScript. A pasta também contém projetos organizados com Node.js, `package.json` e dependências utilizadas durante as práticas.

**Conteúdos praticados:** lógica no back-end, execução de scripts, organização de projetos e uso de pacotes JavaScript.

### [Banco de Dados — MySQL e SQL](./BANCO%20DE%20DADOS%20%5BMYSQL,%20SQL%5D)

Materiais de modelagem, scripts e atividades de banco de dados relacionais.

**Conteúdos praticados:**

- Modelagem conceitual e lógica.
- Relacionamentos entre entidades.
- Comandos DDL, DML, DQL e TCL.
- Criação e alteração de estruturas.
- Inserção, consulta e manipulação de dados.
- Scripts para projetos de Biblioteca, Academia e SmartCoffee.

### [LIMA — HTML e CSS](./LIMA%20%5BHTML,%20CSS%5D)

Atividades de desenvolvimento front-end com HTML e CSS, incluindo exercícios de estruturação, estilização, layouts, wireframes e identidade visual.

Entre os materiais estão práticas e projetos como **DevSolutions**, **SmartCoffee**, páginas institucionais, exercícios de CSS e atividades de interface.

### [Projetos Gerais](./PROJETOS%20%5BGERAL%5D)

Projetos integradores e atividades desenvolvidas individualmente ou em grupo, incluindo páginas web e diferentes versões do projeto SmartCoffee.

### [Aplicativos e ferramentas](./APLICATIVOS%20%5BGERAL%5D)

Ferramentas e arquivos auxiliares utilizados durante as atividades do termo, incluindo o **brModelo** e materiais de apoio para modelagem e desenvolvimento.

## Como utilizar

Clone o repositório principal e acesse a disciplina ou atividade desejada:

```bash
git clone https://github.com/L3onardoDev/Curso-Dev.git
cd Curso-Dev/2-Termo
```

### Executar páginas HTML

Abra o arquivo `.html` no navegador ou utilize a extensão **Live Server** no VS Code.

### Executar projetos JavaScript

Entre na pasta do projeto que possui `package.json`, instale as dependências e execute o arquivo indicado pela atividade:

```bash
npm install
node caminho/para/o/arquivo.js
```

### Utilizar scripts SQL

Os arquivos `.sql` podem ser executados em um ambiente MySQL, como MySQL Workbench ou outro cliente compatível.

> Os comandos podem variar de acordo com a atividade e com o banco de dados configurado localmente.
